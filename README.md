#  TTC Festival Memory Game
### 学園祭のための神経衰弱ゲーム

> カードをめくって、ペアを見つけよう！
> ペアをそろえるたびに、そのカードにまつわる **びっくり豆知識** が表示されます。

## １．概要

###  誰のためのもの？
学園祭に来てくれる人たち（友だち、家族、子どもから大人まで）。だれでも遊べます。

###  なぜ作ったの？
学園祭の日、みんな「今日は思いきり楽しみたい！」という気持ちで来ています。
ステージやお店のあいだには、ちょっとした空き時間があり、
「次は何をしよう？ 楽しいところはどこ？」と探して歩く人がたくさんいます。

私たちの作品を、その「答え」のひとつにしたいと思いました。
数秒で始められて、友だちと一緒に遊べて、思わず笑顔になれるゲーム。
学園祭で楽しい場所を探す人にとって、**私たちのコーナーがその候補のひとつになること**を目指しました。

###  どうやって解決する？
ブラウザを開くだけですぐ遊べる神経衰弱ゲームを作りました。
- 2人で**対戦**できるので、盛り上がります。
- ペアが揃うたびに**豆知識**が出るので、「へえ、そうなんだ！」と会話が生まれます。
- 画面の文字は**日本語と英語**の両方なので、海外からのお客さんも遊べます。

###  できること

| 機能 | 内容 |
|---|---|
|  ひとりで | できるだけ少ない手数で全部のペアをそろえます。⭐ 1〜3個の評価がつきます。 |
|  ふたりで対戦 | 交代でカードをめくり、ペアが多い人の勝ちです。 |
|  タイムアタック | 制限時間内に全部そろえます。ペアをそろえるたびに **+3秒** されます。 |
|  かんたん | 日本の動物（6ペア） |
|  ふつう | 世界の不思議（10ペア） |
|  むずかしい | アニメキャラクター（14ペア） |
|  ベスト記録 | モードとレベルごとのベスト記録を、プレイヤー名つきで保存します（ひとりで・タイムアタックも同様）。2人対戦は、レベル（かんたん・ふつう・むずかしい）ごとに最速の上位3試合を表示するので、レベルの違いで不公平になりません。 |
|  音と演出 | めくる音、そろう音、紙吹雪。音はオン／オフできます。 |

## ２．開発環境・技術スタック

| 項目 | 内容 |
|---|---|
| 使用言語 | HTML5 / CSS3 / JavaScript（フレームワークなし） |
| サーバー | なし（index.html を開くだけ） |
| データベース | なし（ベスト記録はブラウザの localStorage に保存。タブを閉じても残り、そのパソコンの中だけに保存されます） |
| 画面サイズ | 1920 × 1440 を想定して設計。1920 × 1080、2560 × 1440、1366 × 768（13インチノートPC）、スマホ幅でも確認済み |
| ブラウザ | Google Chrome（最新版） |
| AI パートナー | Gemini と Claude（アイデア出し、仕様書、コード、テスト、バグ修正に使用） |
| テスト | 手動テスト表（38 ケース）＋ Playwright による自動チェック |

**使った主な技術**

| 技術 | 使った場面 |
|---|---|
| DOM 操作 | カードの生成、画面の切り替え |
| CSS Grid | カードをきれいに並べる |
| CSS 3D | カードがひっくり返るアニメーション |
| Web Audio API | 効果音を鳴らす |
| Canvas | 紙吹雪を表示する |

## ３．ディレクトリ構造・起動手順

###  ディレクトリ構造

```
memory-game/
├── index.html   … ゲーム本体（HTML・CSS・JavaScript を 1 ファイルにまとめたもの）
├── facts.txt    … カード名と豆知識の一覧（日本語・英語）
├── images/
│   ├── easy/    … 日本の動物の写真（6 枚）
│   ├── normal/  … 世界の不思議の写真（10 枚）
│   └── hard/    … アニメキャラクターの画像（14 枚）
└── fonts/       … 日本語・英語フォント
```

### ▶️ 起動手順（3 ステップ）

1. `memory-game` フォルダをパソコンにコピーします。
2. `index.html` を **Google Chrome** で開きます（ダブルクリックでOK）。
3. モードとレベルを選んで「**スタート！**」を押します。

> インストールもサーバーも不要です。
